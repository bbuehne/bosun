# Contributing

Bosun is a personal tool developed in the open. That shapes what is useful.

**Bug reports: yes, please.** Especially from environments the author cannot
reproduce — corporate VPNs, domain-joined machines, docking stations, bastion
hosts, unusual SFTP server configurations. Include:

- Windows version, WinFsp version, rclone version
- The relevant section of `%LOCALAPPDATA%\Bosun\logs\`
- Your `hosts.toml` with hostnames and usernames redacted
- What state the affected host was in (mounted, probing, unreachable)

**Feature requests: probably no.** Not out of hostility. This tool is reliable
because it is small and serves one workflow. Additions that serve a hypothetical
different user make it worse for the actual one. If you need something
different, forking is encouraged — MIT, do as you like.

**Pull requests:** open an issue first so we can agree the change belongs before
you spend time on it.

**No support commitment.** Responses happen when they happen.
